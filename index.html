🚀 Project 2: Enterprise Hybrid Lab & Splunk SIEM Engineering

Design, deployment, and testing of a multi-subnet corporate architecture built inside EVE-NG. Evaluated perimeter defensive capabilities by routing Red Team exploitation sequences across a site-to-site VPN tunnel while aggregating system, firewall, and web daemon application logs into a central Splunk Enterprise SIEM instance.

Core Engagement Phases:

  • Network Boundary Segmentation & Zero-Trust Architecture: Implemented a multi-interface pfSense gateway to enforce strict isolation between production assets, DMZs, and remote offices while establishing an encrypted IPsec Site-to-Site VPN tunnel.
  • Offensive Security Assessments (Red Team Integration): Executed targeted Nmap discovery sweeps across the VPN to compromise application services on the target LAN machine (192.168.60.131) via a Samba Usermap Script RCE exploit.
  • Web Security & Directory Enumeration: Conducted directory traversal testing and aggressive discovery sweeps with Gobuster against an isolated containerized target running OWASP Juice Shop (172.18.0.2).
  • Log Ingestion Pipeline & Detection Engineering (Blue Team): Configured Splunk Universal Forwarders to harvest kernel authentication logs (`linux_secure`), web daemon streams (`access_combined`), and host shell histories (`bash_history`).

🛡️ Production Detection Engineering Snippets (Splunk SPL):

Alert 1: Scanner and Gobuster Enumeration Traffic
index=web_logs sourcetype=access_combined dest_port=3000 (status=404 OR status=403) | bucket _time span=1m | stats count as error_count, dc(uri_path) as unique_directories_tested, values(http_user_agent) as user_agents by _time, src_ip, dest_ip | where unique_directories_tested > 30 OR searchmatch("gobuster") OR searchmatch("nikto")
